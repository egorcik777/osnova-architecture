# ОСНОВА — архитектурное бюро

Концептуальный сайт архитектурного бюро: арт-дирекшен, адаптивная вёрстка и взаимодействия. HTML, CSS и JavaScript без сборки. Все фотографии и шрифты хранятся в репозитории.

## Просмотр

Откройте `index.html` или включите GitHub Pages: Settings → Pages → GitHub Actions. Workflow `Publish OSNOVA` публикует изменения из `main`.

Во время первого запуска workflow переносит фотографии и шрифты из предыдущей публикации, проверяет их SHA-256 и сохраняет в `assets/` репозитория. Последующие запуски используют локальные файлы. Опубликованный сайт не обращается к предыдущему хостингу.

## Что работает

Восемь страниц проектов, фильтры и два вида каталога, полноэкранная галерея с клавиатурой и свайпом, меню, страницы бюро и контактов. Форма готовит письмо или сохраняет обращение файлом; серверная отправка не подключена.

## Демонстрационный контент

ОСНОВА — вымышленное бюро. Названия, команда, адреса, характеристики и планы концептуальные. Фотографии служат референсами и не являются работами этого бюро. Источники перечислены в разделе «Об изображениях» на сайте.
